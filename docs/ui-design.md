# UI 设计说明（Glass UI）

QuotaLens 的额度栏采用轻量玻璃材质，设置弹窗则使用适配浏览器明暗模式的中性灰阶。

## 设计参考

- [LogRocket — How to create Liquid Glass effects with CSS and SVG](https://blog.logrocket.com/how-create-liquid-glass-effects-css-and-svg/)

视觉实现借鉴了半透明材质、边缘反射高光、内容层与效果层分离、状态反馈及可访问性降级等思路，全程使用原生 CSS 的 `backdrop-filter`、渐变与内外阴影，未复制第三方代码或引入外部运行时库。由于额度栏尺寸会随输入框宽度、附件区及窄屏状态动态变化，未采用固定尺寸的 SVG 位移贴图；本实现属于玻璃风格的网页界面呈现，而非 Apple 原生材质或物理折射效果。

## 界面实现

- **额度栏（`src/content.css`）**：采用 12px 背景模糊、105% 饱和度、轻微高光与内描边，恢复 14px 圆角及约 30px 单行高度；深色模式下使用默认 30% 不透明度的中性灰底色，避免蓝色厚重感。额度数字保持高对比度，绿色、琥珀色与红色进度条对应既定使用率阈值。
- **设置弹窗（`popup.css`）**：通过 `prefers-color-scheme` 跟随浏览器明暗偏好，采用中性实色底、细描边卡片与少量蓝色控件；移除蓝紫渐变及厚重高光，不读取第三方浏览器主题的自定义颜色，弹窗整体保持实色不透视后方网页。
- **主题与辅助功能**：优先采用平台明确指定的主题，无指定时回退至系统偏好；开启“减少透明度”时降级为实色底，开启“减少动态效果”时关闭过渡动画，并支持高对比度与强制颜色模式。
- **键盘与焦点**：折叠与展开均采用原生按钮，支持 `Enter` / `Space` 操作并在切换后将焦点交接至新显示的按钮；非用户点击触发的渲染刷新不抢占输入框焦点。
- **状态指示**：加载、不可用、过期及错误状态采用相应的中性或琥珀色指示标识。

## 布局、透明度与交互细则

- **透明度调节**：`Quota bar transparency` 滑条范围为 0–95%，步长 1%，默认 70%。数值越高，额度栏背景越透明，文字及控件始终保持不透明。设置页使用固定实色卡片，滑条不改变设置页背景。设置保存到本地后实时同步至已有额度栏（含折叠态），且外观变更不会重新发起额度查询；开启“减少透明度”偏好时仍使用实色底。
- **弹窗尺寸**：默认布局（含 Gemini 校准提示）控制在 344px 宽、600px 高以内；展开高级设置后允许纵向滚动。
- **响应式布局**：每组额度采用固定标签、百分比与重置时间列，进度轨道填充剩余宽度。两组额度均分可用空间，窄屏双行模式下保持列对齐。依据输入框实际可用宽度（含视口约束）切换布局：760px 以下隐藏更新时间并使用短时间格式，520px 以下改为双行显示；角落停靠同样使用短时间格式，窄视口下仍保留进度轨道，宽屏下保持约 30px 高度及距输入框 6px 间距。
- **设置简化与交互反馈**：移除全局隐藏开关及其运行时判断（自动清理旧配置中的 `hidden` 字段），保留各平台显示开关与折叠偏好。刷新间隔归入默认收起的高级设置，Gemini 校准提示保留于连接状态区域。Gemini 展开态新增手动刷新按钮，宽屏下与折叠按钮并排，双行及角落停靠时上下排列；刷新期间提供转动反馈并防止重复请求，429 冷却期遵守原有 `Retry-After` 策略。错误与过期读数显示带感叹号的描边警示，紧凑布局隐藏更新时间后仍保留该警示，悬停可查看旧读数状态说明。

## 历史验证记录

- **2026-10-11 布局与首页复核**：在浏览器中检查实际脚本生成的浅色、深色 UI、360px 窄屏、错误提示与键盘交互，调整首版弹窗间距以符合 600px 高度限制。根据用户反馈在已登录的 ChatGPT 首页复核，修复了不在 `<main>` 内的问候标题与额度栏重叠的问题，并补充无 `<main>` 首页回归测试（覆盖折叠/展开、窄屏、草稿与焦点保留及导航后恢复标题样式）。Claude 与 Gemini 该轮仅基于合成页面验证，未新增线上复核。
- **0.1.3 透明度验证**：通过本地实际 UI 文件与模拟 API 复核，随后在用户 Chrome 已安装扩展及真实 ChatGPT 页面完成滑条 0% / 90% 往返视觉验收。复现排查确认更新未打包扩展时须在扩展管理页重新加载扩展并刷新已有平台标签页，以清除旧注入文件缓存；Claude 与 Gemini 当轮未新增线上验收。
- **0.1.4 响应式验证**：视觉复核覆盖浅色/深色主题、240–1440px 输入框宽度及真实 Chrome / ChatGPT 的常规、紧凑与双行布局；真实扩展设置页验证了 0% / 95% 边界、95% → 94% 单步键盘调整及刷新后保存。独立审查复现并修复了宽输入框回退角落停靠及视口约束下的时间截断问题。
- **设置简化与 Gemini 刷新验证**：本地 Chromium 合成页面覆盖浅色/深色模式、240–1000px Gemini 额度栏、错误及恢复、键盘刷新与设置分组。截图已生成，但当时会话图像工具未返回可见图像，尚未完成目视验收，且不代表真实登录页面验证。
