# Glass UI

QuotaLens 的额度栏与弹窗采用受 Apple Liquid Glass 启发的轻量玻璃样式。

## 参考

- [LogRocket — How to create Liquid Glass effects with CSS and SVG](https://blog.logrocket.com/how-create-liquid-glass-effects-css-and-svg/)

借鉴半透明材质、边缘反射高光、内容层与效果层分离、状态反馈和可访问性降级等思路。
本实现使用原生 CSS 的 `backdrop-filter`、渐变和内外阴影，未复制第三方代码或引入运行时库。
由于额度栏会随输入框宽度、附件和窄屏动态变化，未使用固定尺寸 SVG 位移贴图；
这是玻璃风格的网页实现，不是 Apple 原生材质或物理折射效果。

## 实现

- `src/content.css`：12px 背景模糊、105% 饱和度、轻微高光与内描边。
  额度栏恢复 14px 圆角及约 30px 单行高度，深色底使用 24% 不透明度的中性灰，避免蓝色厚重底。
  额度数字保持高对比，绿色/琥珀色/红色进度仍对应原有使用率阈值。
- `popup.css`：独立的深浅主题材质、分组设置、胶囊按钮和原生 checkbox 开关。
  弹窗背景来自自身 CSS 渐变，不宣称能透视其后方网页。
- 保留平台明确指定的主题优先级，系统主题作为回退；减少透明度时使用实色底，
  减少动态效果时关闭过渡；支持高对比及强制颜色模式。
- 折叠和展开使用原生按钮，支持 Enter / Space，并将焦点交给新显示的按钮。
  点击控件之外的渲染刷新不会抢占输入框焦点。
- 加载、不可用、过期及错误状态使用相应的中性或琥珀色指示点。

- 在浏览器查看实际脚本生成的浅色、深色 UI、360px 窄屏、错误提示和键盘交互。

- 用户反馈后在已登录的 ChatGPT 首页复核：修复不在 `<main>` 内的问候标题与额度栏重叠，
  重新加载扩展并刷新后，截图确认标题可见、额度栏不再重叠，颜色与深色页面协调。
- 新增无 `<main>` 首页回归测试，覆盖折叠/展开、窄屏、草稿与焦点保留、导航后恢复标题样式。
- Claude 与 Gemini 本轮仍只验证合成页面，未新增线上复核。
