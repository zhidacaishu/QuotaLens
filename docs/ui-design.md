# Glass UI

QuotaLens 的额度栏保留轻量玻璃材质，设置弹窗采用适配浏览器明暗模式的中性灰阶。

## 参考

- [LogRocket — How to create Liquid Glass effects with CSS and SVG](https://blog.logrocket.com/how-create-liquid-glass-effects-css-and-svg/)

借鉴半透明材质、边缘反射高光、内容层与效果层分离、状态反馈和可访问性降级等思路。
本实现使用原生 CSS 的 `backdrop-filter`、渐变和内外阴影，未复制第三方代码或引入运行时库。
由于额度栏会随输入框宽度、附件和窄屏动态变化，未使用固定尺寸 SVG 位移贴图；
这是玻璃风格的网页实现，不是 Apple 原生材质或物理折射效果。

## 实现

- `src/content.css`：12px 背景模糊、105% 饱和度、轻微高光与内描边。
  额度栏恢复 14px 圆角及约 30px 单行高度，深色底使用默认 30% 不透明度的中性灰，避免蓝色厚重底。
  额度数字保持高对比，绿色/琥珀色/红色进度仍对应原有使用率阈值。
- `popup.css`：通过 prefers-color-scheme 跟随浏览器明暗偏好，采用中性实色底、细描边卡片和少量蓝色控件。
  移除蓝紫渐变及厚重高光；不读取第三方浏览器主题的任意自定义颜色。
  弹窗底色保持实色，不能透视浏览器后方网页。
- 保留平台明确指定的主题优先级，系统主题作为回退；减少透明度时使用实色底，
  减少动态效果时关闭过渡；支持高对比及强制颜色模式。
- 折叠和展开使用原生按钮，支持 Enter / Space，并将焦点交给新显示的按钮。
  点击控件之外的渲染刷新不会抢占输入框焦点。
- 加载、不可用、过期及错误状态使用相应的中性或琥珀色指示点。

## 额度栏透明度与验证

- Quota bar transparency 滑条范围为 0–90%，步长 5%，默认 70%。数值越高，额度栏背景越透明，文字及控件不随背景淡出。设置页使用固定实色卡片，滑条不改变设置页背景。
- 设置保存到本地并实时同步已有额度栏，折叠态同样生效，外观变更不会重新发起额度查询。减少透明度偏好仍使用实色。
- 重新检查浅色／深色截图，验证滑条 0% 与 90% 的额度栏背景变化及设置页背景不变、键盘操作、数值保存及重开恢复。
- 默认布局（含 Gemini 提示）保持 344px 宽、600px 高以内；展开高级设置后允许纵向滚动。
- 本地复核使用实际 UI 文件和模拟 API；随后在用户 Chrome 已安装的扩展及真实 ChatGPT 页面完成滑条 0%/90% 往返视觉验收。
- 线上复现发现 Chrome 仍缓存旧内容脚本/CSS（固定背景 alpha 0.24），扩展管理显示旧版 0.1.1。重新加载扩展至 0.1.2 并刷新网页后，90% 设置对应实际背景 alpha 0.10；设置弹窗保持固定背景。
- 更新未打包扩展时，需要在扩展管理页重新加载扩展，再刷新已有平台标签页；单独重开设置弹窗或刷新网页不足以清除旧注入文件缓存。Claude/Gemini 本次未新增线上验收。
